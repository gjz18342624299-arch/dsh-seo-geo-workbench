# GEO 报告格式

报告以用户确认的品牌档案为准，不预设公司、官网或竞品。计数和占比来自工作台确定性统计，模型不得修改。所有发现应引用记录 ID；事实、推断、数据限制分别说明。

## 表达与阅读顺序

面向运营同事，用通俗中文，结论先行。开头用“一句话结论：”回答最重要的问题、判断和建议，再列最多三条优先建议。先讲问题、结论、建议，再讲证据；不以统计限制、记录 ID 或技术术语开篇。

每项发现依次写“问题：”“结论：”“建议：”“证据与细节：”。标题直接描述问题；详细数字、记录 ID、事实与推断的区分放在依据中。HTML 导出优先展示主要发现与行动，其他分析和依据可展开查看。

行动保留单行格式：P0｜具体行动标题：建议：做什么、改哪个页面或渠道；为什么：问题与依据 [记录ID]；复测：相同条件下如何验收。P1/P2 同理。先给最多三项核心建议，再补充必要事项。给出可执行的文案、案例或操作；待执行建议不写成已经完成。

判定来源统一为“规则自动”“AI 自动”“人工”。auto 对应规则自动，auto-llm 对应 AI 自动，manual 对应人工。自动判定合计 = 规则自动 + AI 自动；其中可能包含仍无法确定归属的样本，不能把合计当成已确认归属的数量。名字提及、归属我方、明确推荐与官网引用分别说明。

总样本数和比例以本次工作台统计为准，不用模型自行清点的子集替代；阅读不完整或分母不一致时明确说明差异。未知基线写未知，先统一范围再设数值目标；不混用比例或声称增长。样本中的产品功能与费用描述只是 AI 的回答，未经核验不当作产品事实。

## 深入分析章节
1. 主要发现：按问题影响排序，每项先说问题、结论、建议，再展开依据与证据 ID。
2. 品牌认知与推荐理由：区分名字出现、正确归属、明确推荐。
3. 竞品场景差异：限于同条件采样结果，不推算市场份额。
4. 引用来源机会：正式引用、检索来源、官网内容缺口分开。
5. 数据缺口：列覆盖范围、失败与未审核样本，不把缺失当作零。
6. 行动与复测：具体页面或渠道、修改建议、优先级、验证方式；附指标、当前基线、下次目标和取数方法。

截图与正文应可回溯；不同模式、问题集和时间窗口不直接合并为增长。报告追问不覆盖已保存的正式报告版本。没有证据时写明未知，不虚构排名、流量、收益或因果关系。

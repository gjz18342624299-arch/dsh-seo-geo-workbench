# SEO/GEO 监测工作台 0.15.4

DSH Desktop 工作台：采集 AI 网站回答、核对品牌证据、导入和分析 SEO 数据，生成可追溯的行动报告。

状态：0.15.4 已在本机真实环境验证并通过安装包检查，发布为 GitHub Release v0.15.4（安装包固定文件名 dsh-seo-geo-workbench.tgz）。看板将“AI 常引用的网站”放在指标、趋势和官网流量区块之后。行动页采用最新已完成 GEO 与 SEO 分析报告的 P0/P1/P2 建议，显示来源版本、数据范围和复测目标；各类新报告出现时延续相关行动的状态，过时建议退出当前清单。支持取消误触复测并暂停待运行任务，保留已采集结果；历史报告加载预览修复为按来源版本显示深入分析结果。浏览器采集与付费模型端到端验收仍需单独完成；macOS / Linux 未验证，不声明兼容。工作台市场收录以 awesome-dsh-workbench 的收录 PR 审核为准，未合并前不宣称已上架。许可证 MIT。

## 界面

工作台共 6 页，左侧导航进入：

- **行动**：默认页。今天该做什么（待核对采样、采集失败重试、需要登录的平台）、最近批次、动作记录（发帖子/改官网后在这里记一条）与本期变化。
- **看板**：谁在说我们（各平台主体判定矩阵 + 提及漏斗）、趋势与动作效果（提及率曲线叠加动作标记）、SEO·官网流量（渠道、Bing 快赢词、AI 引荐）。
- **采集**：三步走——① 问句（推荐问句、复用上一批、向 DSH 要问题）② 平台（登录状态、自检、添加新平台）③ 运行（重复次数、定时、开始）。下方是任务表与资料导入（文件/粘贴文本），以及 Bing / Cloudflare / GSC 自动同步。
- **证据**：逐条回答原文，主体判定（我方/竞品/混合/未提及）可当场改；批量核对与自动判定在顶部；支持筛选、搜索与 CSV 导出；动作记录被引用时引用链接标绿。
- **报告**：GEO 检测报告与 SEO 检测报告的生成、预览、导出（HTML/Markdown/PDF/CSV）；历史报告固定数据版本，可追问。
- **设置**：品牌信息、浏览器与扩展安装指引、数据源凭证（Bing/Cloudflare/GSC）、执行模型。

## 首次使用
1. 在 DSH 工作台管理中添加并打开本工作台，无需先创建会话。首次打开停在「行动」页，按空状态提示先去「设置」。
2. 在「设置 → 监测品牌」保存品牌名称、官网、别名；可配置所属公司、官方来源、同名实体和一般竞品。
3. 沿用 DSH 已配置的模型。浏览器采集需要在「设置 → 浏览器与扩展」安装随包扩展、配对并登录目标平台；回到「采集」页先做一题自检再扩大批次。
4. 也可以先在「采集 → 资料导入」导入已有 CSV/XLSX/JSON/文本资料体验分析。
5. 首次需要会话时，使用 DSH 目录选择器确认资料位置。取消不创建会话；报告追问使用该报告专属、归属本工作台的原生会话。

新用户没有预填品牌。已有 DSH 品牌的数据保留旧规则；其他品牌只使用自身配置。首版一个数据空间对应一个品牌，已有历史时禁止直接改成另一个品牌。

## 安装与构建
市场版使用普通 npm 包契约，安装器负责依赖。客户端已构建为单文件，安装不执行构建脚本。不要使用旧 Windows ZIP 安装方式作为市场验收。

开发者命令（首次克隆后先执行 `cd vendor && npm ci` 恢复开发依赖；vendor/node_modules 不入库）：

    node sync-client.mjs
    node build.mjs
    node --test test/*.test.mjs
    node test/client-smoke.mjs
    node verify-package.mjs

标准 tgz 可通过 DSH 插件管理器安装：

    dsh plugin --profile web add /path/to/dsh-seo-geo-workbench-0.15.4.tgz --ignore-scripts

随后重启 Harness。官方宿主包使用 peerDependencies；xlsx 与 playwright-core 为普通运行依赖，不会自动下载浏览器。

## 数据与权限
新用户内部数据默认位于 dshHomePath('seo-geo-data')；包内不带业务数据。旧用户明确配置的数据位置保留。不要把数据目录设在插件安装目录。更新和卸载应保留会话、资料与报告。

浏览器扩展当前需要网页访问权限，操作采集标签页并保存回答、来源与截图；登录及验证码由用户处理。分析会向用户在 DSH 配置的模型发送所选资料，会产生该模型的相应用量。SEO 连接使用用户自行配置的数据源凭据。

注意：SEO 数据源凭据当前仍在本地业务状态中保存，系统安全存储迁移尚未完成；不要分享该状态文件、连接码、诊断原始日志或个人采样。发行包采用 files 白名单，排除 deployment.json、业务状态、测试资料及备份。

## 兼容性与验收边界
当前测试环境为 Windows x64，使用 DSH Desktop 0.10.0-test.20260927 随包 Harness 0.1.7-rc.2。隔离环境的标准包安装、配置合成、服务启动和页面检查分层记录，不能替代另一台新电脑的完整桌面验收。

Chrome 为原有采集环境；Edge 扩展和 Brave 尚待实际采集验收，Firefox/Safari 暂用资料导入。PDF 导出依赖系统 Edge，缺少时仍可导出 HTML。macOS/Linux 未验证。定时采集需要 DSH 与已连接浏览器运行。

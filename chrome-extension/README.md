# 浏览器连接扩展 0.5.11

Chrome 为既有采集环境；Edge 采用相同 Chromium 扩展安装方式，尚待实机验收；Brave 为实验兼容。Firefox / Safari 暂不支持，请使用工作台资料导入。

1. 在工作台打开“设置 → 浏览器与扩展”，获取随安装包附带的扩展目录；目录、文件检查结果和本机连接码显示在第 1 步按钮下方。
2. 在已登录 AI 网站的浏览器个人资料打开 chrome://extensions（Edge 为 edge://extensions；Brave 为 brave://extensions）。
3. 开启开发者模式，点击“加载未打包的扩展程序”（部分版本为“加载已解压的扩展程序”），选择第 1 步的 chrome-extension 文件夹。里面应包含 manifest.json，不要选父目录、单个文件或 tgz。
   - Mac：在弹出的文件夹选择窗口按 Command + Shift + G，粘贴完整目录，按回车，再点“选择”。路径可能位于隐藏的 Library / .generations 下，不必逐层寻找。
   - Windows：在文件夹选择窗口地址栏粘贴完整目录，按回车，再点“选择文件夹”。
   - 安装成功后，列表应出现“DSH SEO GEO · 浏览器连接”；文件检查未通过时先重新安装完整工作台包。
4. 打开工具栏拼图图标中的“DSH SEO GEO · 浏览器连接”，粘贴本机连接码，点击“连接并允许采集”并授权。
5. 回工作台检查连接，打开目标平台登录并执行一题自检。

连接码不要分享。当前扩展申请网页访问权限，仅操作工作台创建的标签页；不读取Cookie或密码。回答、引用和截图保存在本机；分析时相关资料会发送给用户配置的模型。DSH和浏览器需保持运行。一次连接一个浏览器实例，切换前先断开。升级后在扩展页重新加载，断线后检查连接或重新配对。
